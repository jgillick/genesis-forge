# Deployment Overview

Exporting a trained environment to a real robot, and the simulation-free runtime
that stands between the policy and the hardware there. See the [deployment guide](../../guide/deployment.md) for the
end-to-end walkthrough.

The training-side API lives in `genesis_forge.deployment`; the robot-side runtime is
the separate `genesis-forge-runtime` package, documented under
[Runtime](../runtime/index.md).
