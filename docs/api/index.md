# Overview

Genesis Forge is organized around four main areas:

- **[Environments](environments/index.md)** — Base classes for building Gymnasium-compatible parallel environments. 
- **[Managers](managers/index.md)** — Pluggable components that handle specific aspects of the environment (actuators, rewards, terminations, observations, terrain, entities, contacts, commands, actions).
- **[MDP Functions](mdp/index.md)** — A toolbox of stateless and stateful functions for rewards, terminations, observations, and resets. 
- **[Wrappers](wrappers/index.md)** — Adapters for RL training libraries (RSL-RL, skrl) and utilities like video recording.
